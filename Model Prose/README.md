# Model Prose — register models

Strong analytic philosophy papers kept as **register models**: read one in full before drafting, for
sentence shapes, paragraph movement, display conventions, and dialectical pacing — **never for
content**. Importing material from a model paper into an essay is plagiarism and a compliance
violation. `.md` files are plain-text mirrors of the `.docx` originals (footnotes included).

## Catalog

| Paper | What to imitate |
|---|---|
| *Epistocracy and the Commitment Problem* (Goldstein, *Philosophy & Public Affairs* 2026) | The full package for a political-philosophy paper: front-loaded thesis, named arguments, displays, objection handling. The strongest overall register anchor. |
| *Tit for Tat and the Ethics of War* | Concrete-before-abstract openings; explaining imported formalism (game theory) from zero in the body; premise-form central argument. |
| *Ghost Authorship Paper* | Longer-form dialectical structure; interleaved objections; footnote discipline. |
