# Exemplars — the few-shot bank of transferable moves

Short annotated passages from published analytic philosophy, each showing **one transferable move**.
Where the casebooks catalog moves broadly, an exemplar gives a single move a short verbatim snippet +
why it works + what to borrow, so the drafting agent has a concrete model when choosing an argument
architecture or landing a sentence. Adapted from the entrant's `acdemwrit` writing system.

## THE RULE THAT GOVERNS THIS FOLDER — moves, never words

These files exist so the essays can use the field's best **techniques**. They must never make the
essays derivative:

1. **Borrow the move, never the sentence.** No phrase, image, case, coinage, or passage from an
   exemplar may appear in an essay. The quotes live here for study; they do not travel.
2. **No pastiche.** An essay should not read as an imitation of any one author. Use at most a couple
   of structural moves per essay, chosen because the argument needs them — and execute them in the
   essay's own material.
3. **Content stays out.** The exemplars' philosophical claims are other people's contributions. If an
   essay engages one of these authors' *views*, that goes through the normal literature pipeline
   (real source, verified cite) — never via the exemplar file.
4. **Judged-on-originality check.** The competition grades originality and accuracy. A move (e.g.,
   "minimal-pair cases," "attack one premise") is common property of the field; a distinctive
   *execution* is not. When in doubt, the copy-critic flags anything that echoes an exemplar too
   closely.

## Where these get used

- **Plan / Outline (Stages 3–4):** the `structure/` bank is a menu of argument architectures — pick
  what fits the selected thesis (a refutation paper vs. a positive-account paper vs. a reframing).
- **Drafting and clarity passes (Stages 5–7):** the `prose/` bank models openings, transitions,
  concessions, objection handling, and cadence.
- **Stage 12 retrospectives:** mint new exemplars when an essay's referees or readings surface a move
  the catalog lacks (one move per file; copy `TEMPLATE.md`).

## Conventions

- One move per file; format = `TEMPLATE.md` (Source · The passage · What makes it work · What to
  borrow). Quotes verbatim and short (≤ ~40 words; fair use); never alter text inside quotation marks.
- One exemplar per distinct move — a second exemplar of the same move adds nothing. Grow the bank on
  demand (Stage 12, or when a reading shows a move the catalog lacks).
