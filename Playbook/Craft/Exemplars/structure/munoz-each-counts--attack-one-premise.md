# Annotated exemplar — Muñoz, "Each Counts for One" (the attack-one-premise engine)

## Source
- **Author / Work:** Daniel Muñoz, *Each Counts for One*, Philosophical Studies
  181, 2024 · munozEachCounts (verify against the source before citing)
- **Why this passage:** the paper's engine — reconstruct each rival argument as a
  displayed, *valid* argument, then locate the one premise that isn't the shared
  ideal, and attack only that.

## The passages
> Why do we save the larger number? Because we do give equal weight to saving
> each. Each counts for one. That is why more count for more.

*(Parfit's argument — quoted exactly, then reconstructed as a numbered display.)*

> In each case, the crucial premise is not equality itself but a further idea
> that Taurek, I argue, can safely reject.

## What makes it work (the lesson)
- **Charity first**: the rival is quoted exactly and rebuilt as a *valid*
  argument, so the refutation can't be accused of strawmanning.
- **One premise takes all the fire.** Validity granted, the whole dispute
  localizes to a single premise ("the crucial premise is not equality itself
  but…") — the reader knows precisely what's being denied and what survives.
- **The display is reused across rivals** with only the crucial premise swapped
  (Balancing Argument → Aggregation Argument → Hsieh et al.), turning three
  refutations into one repeated, auditable template.
- Objections to the author's *own* premises go to footnotes, keeping the engine
  clean in the main text.

## What to borrow
When refuting rivals who share a common ideal: display each argument as valid,
isolate the one premise that goes beyond the shared ideal, deny exactly that —
and reuse the same displayed template for each rival, swapping only the crucial
premise.
