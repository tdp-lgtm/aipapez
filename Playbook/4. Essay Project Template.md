# Essay Project Template — folder structure & checklist

Scaffold every essay with
`python3 "Behind the scenes (Claude)/Build scripts/new_essay.py" "<Essay slug or working title>"`,
which creates the tree below in `Essays/<slug>/`, seeds the Checklist (FIRST, never pre-filled), the
Progress Log, and the Process Log. Everything produced for an essay lives inside its folder.

## Folder structure

| Folder | What it holds |
|---|---|
| `Brief/` | The intake record (topic, constraints, autonomy) and the selected `Argument Sketch.md` (AI-generated; custodian-selected). |
| `Background Readings/` | Real PDFs of the key sources + `Converted text/`. Read these, never training memory. |
| `WIP Docs/` | Working deliverables by type: `Candidates/` (thesis candidates + rankings), `Literature Map/`, `Plan/`, `Outline/` (4A/4B/4C + Coverage Map), `Drafts/`, `Abstract/`, `Referee Reports/`, `Change Logs/` — each main type with its own `Old versions/`. |
| `Methodology/` | `Process Log.md` (append-only, every session) and, at Stage 11, `Methodology Report.md`. |
| `Progress reports/` | Custodian-facing: `Checklist.md`, `Progress Log.md`, the Retrospective. Kept clean enough that the custodian can open the Checklist and know exactly where the essay stands. |
| `Scrap/` | Review artifacts: Claims-to-Verify register, Citation Audit, working notes. |
| `Submission/` | Only what is literally submitted: the final essay PDF and methodology report PDF (built from Markdown at Stage 12 only). |

## Checklist template

The Checklist is the steering wheel: created before any deliverable, worked top to bottom, a row
checked only when its step is genuinely done, with evidence written from the finished artifact.
Auditor verdicts are pasted verbatim into their rows.

```markdown
# Checklist — <essay slug>

## Stage 0 — Setup
- [ ] Intake recorded in Brief/ and Process Log (topic/tradition; slots; autonomy; readings; runway)
- [ ] Folder tree scaffolded; Checklist + Progress Log + Process Log created
- [ ] Competition Brief + Rules — Human Involvement re-read this run
- [ ] Auditor gate — Setup: <verdict line>

## Stage 1 — Idea generation & selection
- [ ] ≥10 candidate contributions generated (WIP Docs/Candidates/)
- [ ] Originality/significance pre-screen run (searches logged)
- [ ] Top 3–5 written up as Argument Sketches, ranked
- [ ] CHECKPOINT 1 — sketch selected (by custodian / autonomously); saved to Brief/
- [ ] Auditor gate — Idea Selection: <verdict line>

## Stage 2 — Literature review
- [ ] Active search done; key sources obtained or flagged
- [ ] Literature Map with open-niche + originality verdict
- [ ] Lenses E, Ac run
- [ ] Auditor gate — Lit Review: <verdict line>

## Stage 3 — Plan
- [ ] Plan: sharpest thesis; the move; section budgets ≤ 6,000; dialectical structure; argument labels
- [ ] All six lenses run
- [ ] Auditor gate — Plan: <verdict line>
- [ ] CHECKPOINT 2 — custodian response (generic) applied & logged

## Stage 4 — Layered outline
- [ ] 4A skeleton (lenses A, E; auditor gate)
- [ ] 4B argument outline (all six lenses; auditor gate)
- [ ] 4C fat outline v0.1 (~1,800–2,400 words)
- [ ] 4C round 1 — completeness: Coverage Map built, gaps closed
- [ ] 4C round 2 — engagement: every key interlocutor in bullets
- [ ] Blind referee memo on outline; accepted items folded in
- [ ] Auditor gate — 4C FINAL: <verdict line>
- [ ] CHECKPOINT 3 — structure signed off; outline locked

## Stage 5 — Draft v1.0
- [ ] Single full-density pass to section budgets; structure preserved; placeholders + (verify) tags
- [ ] Lens Ac; Auditor gate — Draft v1.0: <verdict line>

## Stage 6 — Quality passes
- [ ] Pass 1 / Pass 2 / (Pass 3) — each a new version, changelog line, self-check

## Stage 7 — Clarity & register pass
- [ ] Round 1 (front→back) and Round 2 (back→front) with per-section ledger; converged

## Stage 8 — Custodian read (CHECKPOINT 4)
- [ ] Feedback received, logged verbatim, applied (generic only; flags handled per Rules)

## Stage 9 — Referee panel
- [ ] Round 1: 3 blind referees + case-for-acceptance; consensus implemented; self-check
- [ ] Round 2 (fresh personas): implemented; converged
- [ ] (Pre-submission blind read — after Stage 10)

## Stage 10 — Finishing
- [ ] Integration pass
- [ ] Abstract written last (candidates → critique → synthesis)
- [ ] Citation audit clean; apparatus + bibliography built
- [ ] Copy-critic must-fix list applied
- [ ] Length pass: ≤ 6,000 words excl. bibliography (word_count.py output pasted)
- [ ] Compliance sweep: anonymized; no prompt injection; originality re-checked
- [ ] Auditor gate — Final: <verdict line>

## Stage 11 — Methodology report
- [ ] Report assembled from Process Log; anonymized; custodian-reviewed

## Stage 12 — Ship
- [ ] Submission PDFs built and re-checked (word count, anonymity)
- [ ] Custodian submitted via OpenReview; confirmation noted
- [ ] Retrospective written; playbook updates filed
```
