# Methodology Protocol — logging, the Process Log, and the report

The competition requires a methodology report per submission, uses it to adjudicate the
AI-involvement requirement, and awards up to US$5,000 for creative methodologies, judged largely on
how **comprehensive and clear** the report is. This repository therefore treats process documentation
as a first-class deliverable: **if it isn't logged, it didn't happen.**

## The two artifacts

Each essay folder has a `Methodology/` directory containing:

1. **`Process Log.md`** — the running, append-only session log (raw material + compliance evidence).
2. **`Methodology Report.md`** — assembled at Stage 11 from the Process Log; submitted with the essay.

## The Process Log — append after every working session

One entry per session (or per major autonomous run), newest last. Entry template:

```markdown
## [YYYY-MM-DD] Session N — <stage(s) worked>
- **Models/agents:** <e.g. Claude <version> via Claude Code; subagents spawned (type × count, model tier)>
- **Human messages (verbatim):**
  > <every custodian message from the session bearing on this essay, quoted in full;
  >  for long messages, quote in full anyway — this is the compliance record>
- **AI actions:** <what was generated/revised/searched; which files; candidate counts;
   e.g. "generated 12 thesis candidates; killed 7 on originality pre-screen">
- **Selections:** <who selected what from what set, by what criterion — human selections flagged as such>
- **Tools/retrieval:** <web search, PDFs read, scripts run, memory/context notes>
- **Compliance flags:** <any human message containing philosophical substance: quote it, state that it
   was quarantined and not used, and how work proceeded without it — or "none">
- **Approx. cost/time:** <human minutes; rough machine time/tokens if known>
```

Logging rules:

- **Verbatim means verbatim.** The custodian's messages are quoted, not paraphrased. This is what
  lets the organizers verify that human involvement stayed generic.
- **Distinguish human from AI actions explicitly** — the report must; the log makes that possible.
- Log selection events precisely: "custodian picked sketch #3 of 5" is compliance-relevant data.
- Log negative results too: killed candidates, abandoned theses, failed originality checks. The
  organizers want to learn which elicitation methods work; the dead ends are part of the answer.
- **Chat logs:** the custodian should retain the full Claude Code session transcripts (and is
  strongly encouraged to submit them). Note each session's date and surface (e.g., "Claude Code web
  session") in the log so transcripts can be matched to entries later.

## The Methodology Report — assembled at Stage 11

Anonymized, no word limit. Sections (mirroring what the FAQ asks for):

1. **Summary** — one page: what produced this essay, in what pipeline, with how much human input.
2. **AI models and versions** — every model used, and what each originated.
3. **Scaffold and workflow** — this repository described honestly: the pipeline stages, the subagents
   (blind referee panel, citation auditor, copy critic, integrity auditor), the playbook documents
   the AI reads, and where the workflow is public (if the custodian chooses to link the repo,
   post-anonymization rules permitting).
4. **Topic and thesis selection** — how the topic was chosen (human choice is permitted — say so
   plainly); how many candidate contributions were generated; how they were screened and ranked; who
   made the final selection.
5. **Generation and revision** — outline layers, draft, quality passes, referee rounds: how many of
   each, what each changed, what automated evaluation was used.
6. **Every form of human involvement** — verbatim or exhaustively summarized: intake answers,
   selections, generic feedback given at checkpoints, deletions requested. Include any compliance
   flags and how they were handled.
7. **Tools available** — retrieval, web search, PDFs supplied, memory settings.
8. **Resources** — approximate human time, machine time, token usage, and financial cost.
9. **Records** — chat-log retention statement (and the logs themselves, if submitted).

Report discipline: clearly separate "a human did X" from "an AI did X" in every sentence where it
could be ambiguous. Do not include private material — the report will be published (CC BY 4.0);
redact before submission. No prompt injection; no identifying details.

## Division of labor (standing)

- **The AI** writes the essay, the Process Log entries, and the Methodology Report.
- **The custodian** retains chat transcripts, handles OpenReview, and owns the submit button.
