# Literature Access Protocol — how the agent gets real sources

The agent cannot download paywalled papers, but engagement-with-the-literature and accuracy are
graded criteria, and fabrication is forbidden. The solution is a standing request loop: **the agent
asks; the custodian fetches.** (Compliance note: the competition explicitly permits "providing a
paper, passage, dataset, or body of literature for the AI to analyse." Because the AI composes the
request lists itself, there is also no risk of the custodian's curation smuggling in an argument —
record the list and the fulfillment in the Process Log anyway.)

## The request loop

1. **The agent maintains, per essay, `Background Readings/REQUESTS.md`** — a running table of the
   sources it wants, updated whenever a need appears (Stage 1 pre-screens, Stage 2 lit review,
   referee rounds, citation audits):

   | # | Source (author, year, title, venue) | Why needed | Priority | Status |
   |---|---|---|---|---|
   | 1 | … | key rival; must engage closely | HIGH | REQUESTED 2026-09-22 |
   | 2 | … | verify one attributed claim | MED | RECEIVED 2026-09-25 |

2. **The agent pings the custodian in chat** at natural bundling points — never one paper at a
   time; batch the list, ordered by priority, with one line each on why. Distinguish **must-have**
   (load-bearing rival or source of an attributed claim) from **nice-to-have** (background,
   spot-checks).
3. **The custodian uploads** the files into the essay's `Background Readings/` — PDFs or Markdown
   conversions both work (Markdown is fine; keep the original pagination markers if converting, so
   pinpoint cites remain checkable — a simple `[p. 123]` at each page break is enough).
4. **The agent updates the status column**, converts PDFs to text in `Converted text/`, reads, and
   logs the delivery in the Process Log.

## Discipline

- **Before requesting:** exhaust what's free — the agent has web access (WebSearch/WebFetch) and
  should first try open sources: PhilPapers records and archived preprints, SEP, personal pages,
  institutional repositories. Request only what it cannot legitimately reach.
- **While waiting:** a missing must-have source blocks only the claims that depend on it — tag those
  `(verify — awaiting source #N)` and keep working elsewhere. Never paraphrase an unread source from
  training memory: what the essay says a work argues must come from the work.
- **A request is never a stall.** Each ping to the custodian names what the agent will do in the
  meantime.
- **Pinpoints:** page-level cites are only made from sources on disk (or verbatim-quoted in a
  verified web source). A source read only as an abstract supports only what the abstract says.
- The citation-auditor treats the REQUESTS table as part of its evidence: an attributed claim whose
  source was never RECEIVED is automatically UNVERIFIABLE.
